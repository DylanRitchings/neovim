The Goal
---
Create commands that:
- Go up and down JSON objects
- Cycle through each object at the same level

<!-- end_slide -->
The Solution
---
Use Tree-sitter to create commands that navigate JSON
<!-- new_lines: 5 -->

What is Tree-sitter?
---
Tree-sitter is a program that parses source code into a syntax tree, allowing programs to easily analyse and manipulate code. 
<!-- new_lines: 1 -->
Features:
- Language agnostic
- Fairly easy to use
